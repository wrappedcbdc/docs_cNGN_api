---

This endpoint returns every transaction recorded against your business account — including fiat deposits, on-chain withdrawals, cNGN redemptions, and cross-chain bridges — sorted with the most recent first. Use the `page` and `limit` query parameters to step through large histories. The `data` field in the raw response is Ed25519-encrypted; all examples below show the **decrypted** payloads.

## Query parameters

<ParamField query="page" type="number" default="1">
  The page of results to return. Starts at `1`.
</ParamField>

<ParamField query="limit" type="number" default="10">
  Number of transaction records to include per page. Increase this value to
  reduce the number of round trips when fetching large histories.
</ParamField>

## Response fields

<ResponseField name="data" type="object[]">
  Array of transaction records for the requested page.

  <Expandable title="Transaction object">
    <ResponseField name="id" type="string">
      Unique identifier for this transaction.
    </ResponseField>

    <ResponseField name="from" type="string">
      Sender identifier — either a business name, an on-chain address, or an
      internal cNGN system identifier.
    </ResponseField>

    <ResponseField name="receiver" type="object">
      Destination of the transaction. The shape depends on the transfer type:

      - **On-chain transfer:** `{ "address": "0x..." }` — the destination wallet address.
      - **Fiat settlement:** `{ "bank": "Bank Name", "accountNumber": "0123456789" }` — the destination bank account.
    </ResponseField>

    <ResponseField name="amount" type="string">
      Transaction amount as a decimal string (e.g. `"5000.00"`).
    </ResponseField>

    <ResponseField name="description" type="string">
      Human-readable summary of the transaction.
    </ResponseField>

    <ResponseField name="status" type="string">
      Current state of the transaction. One of `pending`, `success`, or
      `failed`.
    </ResponseField>

    <ResponseField name="trx_type" type="string">
      Transaction category. One of `deposit`, `withdrawal`, `redeem`, or
      `swap`.
    </ResponseField>

    <ResponseField name="network" type="string">
      Blockchain network the transaction was executed on. Present for on-chain
      transfers and bridges.
    </ResponseField>

    <ResponseField name="trx_ref" type="string">
      Unique transaction reference. Pass this to
      [Verify Withdrawal](/api-reference/verify-withdrawal) to poll status.
    </ResponseField>

    <ResponseField name="asset_type" type="string">
      Asset classification (e.g. `credit_alphanum4`).
    </ResponseField>

    <ResponseField name="asset_symbol" type="string">
      Asset ticker. Always `CNGN`.
    </ResponseField>

    <ResponseField name="base_trx_hash" type="string | null">
      On-chain transaction hash on the origin network. `null` for fiat
      transactions.
    </ResponseField>

    <ResponseField name="extl_trx_hash" type="string | null">
      On-chain transaction hash on the destination network (bridges only).
      `null` otherwise.
    </ResponseField>

    <ResponseField name="explorer_link" type="string | null">
      Direct URL to the transaction on the relevant block explorer. `null` for
      fiat transactions.
    </ResponseField>

    <ResponseField name="createdAt" type="string">
      ISO 8601 timestamp of when the transaction was created.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="pagination" type="object">
  Metadata for navigating the full result set.

  <Expandable title="Pagination object">
    <ResponseField name="count" type="number">
      Total number of transactions across all pages.
    </ResponseField>

    <ResponseField name="pages" type="number">
      Total number of pages given the requested `limit`.
    </ResponseField>

    <ResponseField name="isLastPage" type="boolean">
      `true` when the current page is the last one.
    </ResponseField>

    <ResponseField name="nextPage" type="number | null">
      Page number of the next page, or `null` if you are on the last page.
    </ResponseField>

    <ResponseField name="previousPage" type="number | null">
      Page number of the previous page, or `null` if you are on the first page.
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>

```bash cURL
curl -X GET "https://api.cngn.co/v1/api/transactions?page=1&limit=20" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```typescript TypeScript
const params = new URLSearchParams({ page: "1", limit: "20" });

const response = await fetch(
  `https://api.cngn.co/v1/api/transactions?${params}`,
  {
    method: "GET",
    headers: {
      Authorization: `Bearer ${process.env.CNGN_API_KEY}`,
    },
  }
);

const { data } = await response.json();
// data is a base64 Ed25519-encrypted string — decrypt before use
```

```python Python
import requests
import os

response = requests.get(
    "https://api.cngn.co/v1/api/transactions",
    params={"page": 1, "limit": 20},
    headers={"Authorization": f"Bearer {os.environ['CNGN_API_KEY']}"},
)

payload = response.json()
# payload["data"] is a base64 Ed25519-encrypted string — decrypt before use
```
