description: "Fetch the current cNGN balance held by your business account. Returns an array of asset objects with asset type, code, and available balance."
api: "GET https://api.cngn.co/v1/api/balance"
---

Calling this endpoint returns all cNGN balance entries associated with your business account. There are no query parameters or request body — attach your Bearer API key and the API responds with the current available balance as a decimal string. The `data` field in the raw response is Ed25519-encrypted; the example below shows the **decrypted** payload.

## Response fields

<ResponseField name="data" type="object[]">
  Array of asset balance objects held by your account.

  <Expandable title="Balance object">
    <ResponseField name="asset_type" type="string" required>
      Asset classification returned by the underlying ledger. For cNGN this is
      always `credit_alphanum4`.
    </ResponseField>

    <ResponseField name="asset_code" type="string" required>
      Ticker symbol of the asset. Always `CNGN`.
    </ResponseField>

    <ResponseField name="balance" type="string" required>
      Current available balance represented as a decimal string (e.g.
      `"150000.00"`). Use string arithmetic when processing to avoid
      floating-point drift.
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>

```bash cURL
curl -X GET "https://api.cngn.co/v1/api/balance" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json"
```

```typescript TypeScript
const response = await fetch("https://api.cngn.co/v1/api/balance", {
  method: "GET",
  headers: {
    Authorization: `Bearer ${process.env.CNGN_API_KEY}`,
    "Content-Type": "application/json",
  },
});

const { data } = await response.json();
// data is a base64 Ed25519-encrypted string — decrypt before use
```

```python Python
import requests
import os

response = requests.get(
    "https://api.cngn.co/v1/api/balance",
    headers={
        "Authorization": f"Bearer {os.environ['CNGN_API_KEY']}",
        "Content-Type": "application/json",
    },
)

payload = response.json()
# payload["data"] is a base64 Ed25519-encrypted string — decrypt before use
```

</RequestExample>
