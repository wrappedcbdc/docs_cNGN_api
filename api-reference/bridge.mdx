title: "POST /bridge — Move cNGN Between Blockchain Networks"
sidebarTitle: "Bridge"
api: "POST https://api.cngn.co/v1/api/bridge"
description: "Initiate a cross-chain cNGN bridge. Receive a deposit address on the origin network; the equivalent cNGN is delivered to your chosen destination address."
---

Use this endpoint to move cNGN from one supported blockchain network to another. The API responds with a `receivableAddress` on the origin network — you send your cNGN to that address, and the equivalent amount (minus fees) is automatically delivered to `destinationAddress` on the destination network. Before calling this endpoint, use [Bridge Quote](/api-reference/bridge-quote) to preview the fees and receivable amount. Your request body must be AES-256-CBC encrypted and sent as `{ content, iv }` — see the [Encryption guide](/guides/encryption) for implementation details. The **Swap** permission must be enabled on your API key.

<Note>
  The `data` field in every response is Ed25519-encrypted. The examples on this page show the **decrypted** payload for readability.
</Note>

<Warning>
  Only send cNGN to the `receivableAddress` returned in the response. Sending any other token, or sending to a different address, may result in permanent loss of funds.
</Warning>

## Request body

The fields below describe the **plain JSON object you encrypt before sending**. Do not send these fields directly — wrap the encrypted result in `{ "content": "<ciphertext>", "iv": "<iv>" }`.

<ParamField body="originNetworkId" type="string" required>
  ID of the network you are bridging **from**. Retrieve valid IDs from [Get Networks](/api-reference/get-networks).
</ParamField>

<ParamField body="destinationNetworkId" type="string" required>
  ID of the network you are bridging **to**.
</ParamField>

<ParamField body="destinationAddress" type="string" required>
  Wallet address that will receive cNGN on the destination network.
</ParamField>

<ParamField body="senderAddress" type="string">
  Address you will send cNGN from on the origin network. Providing this enables stricter validation and is recommended.
</ParamField>

<ParamField body="callbackUrl" type="string">
  HTTPS URL to notify when the bridge completes. The URL will receive a POST request when the bridge completes.
</ParamField>

## Response

<ResponseField name="receivableAddress" type="string">
  Deposit address on the origin network. Send the cNGN you want to bridge to this address to trigger the cross-chain transfer.
</ResponseField>

<ResponseField name="transactionId" type="string">
  Internal transaction ID for the bridge operation.
</ResponseField>

<ResponseField name="reference" type="string">
  Human-readable bridge reference for tracking and support queries (e.g. `BR-5d4c3b2a`).
</ResponseField>

<Tip>
  Call [Bridge Quote](/api-reference/bridge-quote) with the same `amount`, `originNetworkId`, `destinationNetworkId`, and `destinationAddress` before submitting this request. Quote the exact amount you plan to send so your users see a confirmed delivery figure.
</Tip>

```bash cURL
curl -X POST "https://api.cngn.co/v1/api/bridge" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "content": "<base64 AES-256-CBC ciphertext of the plain body>",
    "iv": "<base64 16-byte IV>"
  }'
```
