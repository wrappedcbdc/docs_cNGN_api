This endpoint returns every blockchain network that cNGN currently supports for on-chain withdrawals, cross-chain bridging, and address whitelisting. The `id` field of each network object is what you pass as `networkId` in those other endpoints — always resolve it dynamically rather than hard-coding it, because IDs differ between the test and live environments. The `data` field in the raw response is Ed25519-encrypted; the example below shows the **decrypted** payload.

<Note>
  Network `id` values are environment-specific. An ID that works in the test
  environment will not match the same network in production. Always call this
  endpoint at runtime to look up the correct `networkId` for the environment
  your request is targeting — never hard-code network IDs.
</Note>

## Query parameters

<ParamField query="includeBlockchain" type="boolean" default="false">
  Set to `true` to include underlying blockchain metadata (chain ID, RPC
  details, etc.) nested inside each network object. Omit or set to `false` when
  you only need the network `id` and display name.
</ParamField>

## Response fields

<ResponseField name="data" type="object[]">
  Array of supported network objects.

  <Expandable title="Network object">
    <ResponseField name="id" type="string" required>
      Unique network identifier. Pass this value as `networkId` in withdrawal,
      bridge, and whitelist requests.
    </ResponseField>

    <ResponseField name="name" type="string" required>
      Full, human-readable network name (e.g. `"Base"`, `"Polygon"`).
    </ResponseField>

    <ResponseField name="short_name" type="string" required>
      Abbreviated network code (e.g. `"BASE"`, `"POLYGON"`). Useful for
      display in your UI.
    </ResponseField>

    <ResponseField name="isDisabled" type="boolean" required>
      When `true`, this network is temporarily unavailable. Transfers submitted
      against a disabled network will be rejected. Filter these out before
      presenting network options to users.
    </ResponseField>

    <ResponseField name="blockchain" type="object | null">
      Additional blockchain metadata. Populated only when
      `includeBlockchain=true` is passed; otherwise `null`.
    </ResponseField>
  </Expandable>
</ResponseField>

<Warning>
  Networks where `isDisabled` is `true` cannot be used for withdrawals,
  bridges, or address whitelisting. Always check this flag before submitting a
  transfer request and surface a clear message to your users when their
  preferred network is temporarily unavailable.
</Warning>

<RequestExample>

```bash cURL
curl -X GET "https://api.cngn.co/v1/api/networks" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```bash cURL (with blockchain metadata)
curl -X GET "https://api.cngn.co/v1/api/networks?includeBlockchain=true" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
