---

Before initiating a cross-chain bridge, call this endpoint to see exactly how much cNGN will arrive at the destination and what fees will be deducted. The quote covers both the on-chain network fee and the cNGN bridging service fee, so you can surface an accurate preview to your users. Quotes are non-binding — no funds move until you call [Bridge](/api-reference/bridge). Your request body must be AES-256-CBC encrypted and sent as `{ content, iv }` — see the [Encryption guide](/guides/encryption) for implementation details. The **Swap** permission must be enabled on your API key.

<Note>
  The `data` field in every response is Ed25519-encrypted. The examples on this page show the **decrypted** payload for readability.
</Note>

## Request body

The fields below describe the **plain JSON object you encrypt before sending**. Do not send these fields directly — wrap the encrypted result in `{ "content": "<ciphertext>", "iv": "<iv>" }`.

<ParamField body="amount" type="number" required>
  Amount of cNGN you intend to bridge. The quote will show how much arrives after fees are deducted.
</ParamField>

<ParamField body="originNetworkId" type="string" required>
  ID of the network you are bridging **from**. Retrieve valid IDs from [Get Networks](/api-reference/get-networks).
</ParamField>

<ParamField body="destinationNetworkId" type="string" required>
  ID of the network you are bridging **to**.
</ParamField>

<ParamField body="destinationAddress" type="string" required>
  Wallet address that would receive cNGN on the destination network.
</ParamField>

## Response

<ResponseField name="amountReceivable" type="string">
  Amount of cNGN that will arrive at the destination address after all fees are applied.
</ResponseField>

<ResponseField name="networkFee" type="string">
  On-chain gas or relay fee for the bridge transaction, denominated in cNGN.
</ResponseField>

<ResponseField name="bridgeFee" type="string">
  cNGN service fee charged for executing the cross-chain bridge.
</ResponseField>

<Tip>
  Add `networkFee` and `bridgeFee` to `amountReceivable` to recover the original `amount` you submitted. Display `amountReceivable` to your users as the confirmed delivery amount.
</Tip>

```bash cURL
curl -X POST "https://api.cngn.co/v1/api/bridge-quote" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "content": "<base64 AES-256-CBC ciphertext of the plain body>",
    "iv": "<base64 16-byte IV>"
  }'
```
