description: "Register an external wallet address on a specific network so it is authorised to receive cNGN withdrawals from your account. Returns the updated whitelist."
---

Use this endpoint to register an external wallet address against a specific network, authorising it to receive cNGN withdrawals from your account. Once whitelisted, the address can be passed directly to [Withdraw](/api-reference/withdraw), or it will be auto-accepted if your account requires address pre-approval. Your request body must be AES-256-CBC encrypted and sent as `{ content, iv }` — see the [Encryption guide](/guides/encryption) for how to prepare the payload. After a successful call, the response returns your **full updated list** of whitelisted addresses, so you always have the current state in a single round-trip.

<Note>
  The `data` field in every response is Ed25519-encrypted. The examples on this page show the **decrypted** payload for readability.
</Note>

## Request body

The fields below describe the **plain JSON object you encrypt before sending**. Do not send these fields directly — wrap the encrypted result in `{ "content": "<ciphertext>", "iv": "<iv>" }`.

<ParamField body="networkId" type="string" required>
  ID of the network the address belongs to. Retrieve valid IDs from [Get Networks](/api-reference/get-networks).
</ParamField>

<ParamField body="address" type="string" required>
  The external wallet address you want to whitelist. Must be a valid address format for the specified network.
</ParamField>

## Response

Returns your updated list of all whitelisted addresses across all networks as an array.

<ResponseField name="data" type="object[]">
  <Expandable title="Whitelisted address object">
    <ResponseField name="id" type="string">
      Unique identifier for this whitelist entry.
    </ResponseField>
    <ResponseField name="networkId" type="string">
      ID of the network this address is whitelisted on.
    </ResponseField>
    <ResponseField name="publicKey" type="string">
      The whitelisted external wallet address.
    </ResponseField>
    <ResponseField name="internalPublicKey" type="string">
      Internal deposit address paired to this whitelist entry by cNGN.
    </ResponseField>
    <ResponseField name="network" type="object">
      Network summary object (`id`, `name`, `short_name`). Present when `includeNetwork=true` is used on [Get Whitelisted Addresses](/api-reference/get-whitelisted-addresses).
    </ResponseField>
    <ResponseField name="created_at" type="string">
      ISO 8601 timestamp when the entry was created.
    </ResponseField>
    <ResponseField name="updated_at" type="string">
      ISO 8601 timestamp of the most recent update to this entry.
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>

```json Plain body (encrypt before sending)
{
  "networkId": "9b2e6a1f-3c4d-4e5f-8a7b-1c2d3e4f5a6b",
  "address": "0xAbCdEf1234567890AbCdEf1234567890AbCdEf12"
}
```

```bash cURL
curl -X POST "https://api.cngn.co/v1/api/whitelist" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "content": "<base64 AES-256-CBC ciphertext of the plain body>",
    "iv": "<base64 16-byte IV>"
  }'
```

```typescript TypeScript
const payload = JSON.stringify({

  address: "0xAbCdEf1234567890AbCdEf1234567890AbCdEf12",
});

// Encrypt `payload` with AES-256-CBC, then send:

  headers: {
    Authorization: `Bearer ${API_KEY}`,

  },

const { data } = await res.json();
```
