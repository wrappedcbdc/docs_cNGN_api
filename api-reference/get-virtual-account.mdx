---
title: "Get Virtual Account"
api: "GET https://api.cngn.co/v1/api/virtual-account"
description: "Retrieve your dedicated virtual account(s) for Naira deposits"
---

Returns the dedicated virtual bank account(s) assigned to your business. Naira transferred into these accounts is automatically converted and credited as cNGN.

<Note>
Requires the **Fiat Deposit** permission. See [Permissions](/guides/permissions).
</Note>

### Response (decrypted `data`)

<ResponseField name="data" type="object[]">
  <Expandable title="Account object">
    <ResponseField name="accountNumber" type="string">10-digit NUBAN account number.</ResponseField>
    <ResponseField name="accountName" type="string">Account name (your registered business name).</ResponseField>
    <ResponseField name="bankName" type="string">Bank hosting the virtual account.</ResponseField>
    <ResponseField name="bankCode" type="string">CBN bank code.</ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>

```bash cURL
curl -X GET "https://api.cngn.co/v1/api/virtual-account" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```typescript TypeScript
const res = await fetch("https://api.cngn.co/v1/api/virtual-account", {
  headers: { Authorization: `Bearer ${API_KEY}` },
});
```

```python Python
res = requests.get(
    "https://api.cngn.co/v1/api/virtual-account",
    headers={"Authorization": f"Bearer {API_KEY}"},
)
```

</RequestExample>
